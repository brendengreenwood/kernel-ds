## 2026-09-04 — Green acts, blue navigates: the nav-blue traversal color (decision 0069)

**What:** The cobalt scale from the unmerged action-blue concept (PR #61)
lands in the DS with its roles inverted per owner direction: Cargill
green stays the action color exactly as 0067 shipped it; the blue is the
navigation/traversal color. Added `--nav-*` (full 50→950 + aliases, the
PR #61 ramp values unchanged) and a `--traversal` ink role token
(nav-600 light / nav-400 dark) to `packages/ui/src/styles.css`, and
wired the traversal signifiers in `@kernel/ui`: breadcrumb links
(text-traversal + hover underline), accordion trigger chevrons, tabs
actives (pill fills bg-traversal — white text light / nav-950 dark —
and underline borders border-traversal; tabs no longer ride --primary),
pagination's current page (soft nav chip, ghost otherwise), and sidebar
selection (light nav-100/nav-800 chip; dark keeps the raised
neutral-800 chip per 0065's elevation logic and signals with a nav-300
label — deliberately revisiting the register note that made rail
selection neutral, which guarded against a second green, not a blue).
Foundations Color page gains the Nav ramp + the "green does, blue goes"
blurb; contrast-audit gains a "Traversal (nav blue)" section. The v1
concept archive doc is restored to the tree (screenshots live in PR
#61's tree at 03d204f and its Netlify deploy preview).

**Why:** Owner insight after sitting with the v1 concept: the split is
right, the assignment was backwards — blue links are the web's oldest
traversal convention and the brand belongs on the buttons users act on.
On current main this is purely additive: 0067 already ratified
green/lime as the action hue, so only the blue half was missing.

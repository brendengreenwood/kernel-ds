## 2026-09-03 — AGENTS.md citation gate + the stale lines it found

**What:** Added `agents-citations`, a `ds:doctor` check that reads every
`AGENTS.md` and `CLAUDE.md` outside the generated marker blocks and requires
each cited path and `npm run` script to resolve (decision 0069). The gate is a
pure library (`scripts/ds/lib/agents-citations.mjs`) with a red fixture in
`scripts/ds/__fixtures__/agents-stale-citation/` and assertions in
`scripts/ds/__check__.mjs` that it flags exactly the stale lines and stays quiet
on placeholders, prose slashes, package specifiers, and gitignored outputs.
Then fixed everything its first run reported: the token sheet is
`packages/ui/src/styles.css`, not `kernel-portal/src/index.css` (CLAUDE.md,
portal AGENTS, portal README, ui AGENTS); the icon shim is `@kernel/ui/icon`,
not `@/components/ui/icon`; the marks `__check__` and the ui primitives live in
`packages/ui`, not under the portal; the portal has no `hooks/` or
`pages/gallery/` (demos are the `gallery-*.tsx` clusters registered in
`lib/gallery-registry.ts`); the studio has no `mastra/public/`; three prose
slashes (`docs/design`, `docs/gallery`, `docs/internal`) were rewritten as
words so they no longer read as paths. Regenerated the AGENTS inventories so
the doctor-checks list carries the new id.

**Why:** Decision 0038 deferred a gate for the hand-written citations, and the
ui-package extraction then left a dozen guidance lines pointing at files that
had moved. The generated blocks in the same files updated themselves; the prose
three lines above them did not, and an agent reading `kernel-portal/AGENTS.md`
cold would have run a gate at a path that does not exist. The doctor already
runs in CI's `automation` job, so the gate is enforced from this commit on.

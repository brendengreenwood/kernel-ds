# Worklog — 2026-11

## 2026-11-01 — Iso-glow grain-dump scene on the Motion page

- **What:** Added `GrainDumpScene`, an isometric "iso glow" illustration loop on `/motion`. A hopper-bottom truck pulls onto the receiving pit, opens its gates, and corn streams through the grate. The bucket leg lifts it to the bin while the bin's fill gauge rises, then the truck scales out. A footer shows load ID, `CommodityBadge`, phase, a bushel counter, and Play/Pause/Replay controls. Added `Play`, `Pause`, `RotateCcw` to the MDI icon shim.
- **Why:** Request for a polished receiving-pit animation in the iso-glow style. It's a reusable illustration for empty states, onboarding and the receiving dashboard, and it shows that choreographed motion can stay token-driven.
- **How:** Pure SVG with a 2:1 iso projection helper. One deterministic timeline `frame(t)` drives every element, so pause, replay and the reduced-motion still frame all render from a single `t`. Easing evaluates the `--ease-out` / `--ease-in-out` token curves in JS. Colour is all theme tokens (`--card`/`--muted`/`--foreground` faces, `--primary` edges, `--commodity-corn-*` glow), so it follows light/dark. Reduced motion → still frame mid-unload with Play as an explicit opt-in. rAF pauses off-screen via IntersectionObserver. Glow filters use `userSpaceOnUse` regions, because an objectBoundingBox filter on a straight vertical/horizontal line has a zero-size region and erases it.
